# RoamBench Logo Drafts

This folder contains three lightweight SVG logo directions for `RoamBench`.

These are intentionally small-scope draft assets:

- vector only
- transparent canvas outside the icon
- horizontal lockup with an icon at the left and the `RoamBench` wordmark at the right
- suitable for README, GitHub release notes, and social preview mockups

## Concepts

### Concept A: Grid Loop

File: [roambench-concept-a-grid-loop.svg](roambench-concept-a-grid-loop.svg)

- strongest match for the product today
- emphasizes `1 / 2 / 4`-pane layouts and multi-view workspace structure
- adds a reconnect loop to suggest "resume from anywhere"
- best candidate for the first public logo

### Concept B: Roam Path

File: [roambench-concept-b-roam-path.svg](roambench-concept-b-roam-path.svg)

- more mobile and travel-oriented
- uses a path with checkpoints to suggest roam / reconnect / resume
- feels lighter and more lifestyle-oriented than Concept A

### Concept C: Beacon Bench

File: [roambench-concept-c-beacon-bench.svg](roambench-concept-c-beacon-bench.svg)

- more serious devtool / infra feel
- uses a bench-like pane stack with a beacon signal
- strongest fit if you want a more technical, less consumer-feeling identity

## Recommendation

Pick **Concept A** if you want the safest balance of:

- split-view workspace signal
- reconnect / resume signal
- compact GitHub-friendly appearance
- terminal-first tool personality without becoming a generic `>_` logo

## Avatar Guidance

Recommended split:

- personal GitHub account: founder photo
- product org / repo avatar: `RoamBench` icon

That keeps the founder identity and product identity separate, which is usually stronger for an open-source devtool.
