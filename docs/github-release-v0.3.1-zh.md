# RoamBench v0.3.1 发布说明（中文）

## 变更概述

`v0.3.1` 主要补了三类东西：

- README 和发布材料补上了真实的移动端重连截图
- 文件浏览器里的文件项改成了更清晰的文件类型徽标
- GitHub Release 的二进制打包流程收口成了可复用的正式路径

## 主要更新

- README / launch 文案现在不再只停留在“可以手机接回”，而是有真实截图支撑
- 文件浏览器会按目录、图片、代码、压缩包、文档等类型显示简短徽标
- 新增通用打包脚本，可生成 Linux `amd64` / `arm64` 压缩包与对应 `.sha256`
- 新增通用安装脚本，可按 tag 从 GitHub Releases 自动匹配正确资产

## 发布与打包

本次版本开始，建议用下面这条命令生成 release 资产：

```bash
make release-packages TAG=v0.3.1
```

建议附带的发布资产：

- Linux `amd64` 压缩包
- Linux `arm64` 压缩包
- 两个压缩包对应的 `.sha256` 校验文件

## 短版发布文案

`RoamBench v0.3.1 补上了真实的移动端重连证明、文件类型徽标，以及可复用的 Linux 二进制发布流程。`
