# RoamBench v0.3.2 发布说明（中文）

## 变更概述

`v0.3.2` 主要把内置文件查看流转补完整，让更多文件都能稳定留在 Viewer 里处理，而不是意外跳到浏览器兜底或上下分屏编辑。

## 主要更新

- Viewer 现在可以直接预览 DOCX 和 XLSX，PPTX 也补上了页内翻页导航
- 文件列表点击会优先走 Viewer，因此像无扩展名纯文本文件也不会再意外触发上下分屏编辑器
- 单终端桌面布局下，右侧嵌入式文件面板现在可以横向拖宽
- Chromium 系浏览器里，内置 PDF 预览不再因为扩展中转而报“拒绝连接”

## 发布与打包

本次版本建议继续用下面这条命令生成 release 资产：

```bash
make release-packages TAG=v0.3.2
```

建议附带的发布资产：

- Linux `amd64` 压缩包
- Linux `arm64` 压缩包
- 两个压缩包对应的 `.sha256` 校验文件

## 短版发布文案

`RoamBench v0.3.2 补上了 DOCX/XLSX 预览、修正了 Viewer-first 文件打开流转、改善了内嵌 PDF 兼容性，并让单终端布局下的文件面板可以横向调宽。`
